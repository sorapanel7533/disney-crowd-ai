# 管理者画面の設定

1. Streamlit Community Cloudで対象アプリの **Settings → Secrets** を開きます。
2. 既存の行を残し、トップレベルに `ADMIN_VIEW_PIN = "所有者が指定した4桁"` を追加します。引用符を含めて数字を文字列で保存します。
3. 保存後、公開サイトの「管理者画面」でPINを入力すると、詳細表やX投稿用文面を閲覧できます。PINが未設定なら閲覧は閉じたままです。
4. 投稿審査・補足入力・その他の管理操作には既存の `ADMIN_PASSWORD_SHA256` または `ADMIN_PASSWORD` が必要です。詳しくは [運用手順](OPERATIONS.md) と [実測待ち時間の運用手順](MEASURED_WAITS.md) を参照してください。
5. 閲覧認証は30分で失効します。共有端末を離れるときは「ログアウト」を押してください。PINの認証失敗は同一セッションと実行プロセスの両方で制限します。
